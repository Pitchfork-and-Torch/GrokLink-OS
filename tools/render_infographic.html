What it is

GrokLink OS is a complete research operating system - kernel, HAL, drivers, services, GUI, and safety path owned end-to-end. It is not a Flipper overlay. Any compatible LLM can treat the device as a passive RF sensory peripheral while TX remains human-gated. v3.8 adds durable host-side persistence without weakening default-deny.

GrokLink RTOS Policy engine Storage API Skills + vault LLM tools ST7567 GUI
Design principles
  • Safety by construction - actuators only via policy
  • USB-safe radio - deferred jobs, never in endpoint IRQs
  • Constrained autonomy - offline missions stay passive
  • Durable when storage ok - vault/skills survive restarts on host
  • Audit everything - append-only + integrity markers
  • Honest silicon - no false capability claims
